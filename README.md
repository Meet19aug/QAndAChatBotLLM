# Online Learning Q&A Bot

## Overview
Welcome to the Online Learning Q&A Bot! This project aims to provide a basic Q&A chatbot for online learning platforms. It utilizes state-of-the-art AI technologies to create a knowledge base from CSV files containing questions and answers, allowing users to interact naturally through a user-friendly interface.

## Features
- **User-Friendly Interface**: Built with Streamlit for simplicity and ease of use.
- **Advanced Language Processing**: Leveraging Langchain and Google's PALM for robust natural language understanding.
- **Efficient Data Handling**: Utilizes FAISS for fast and efficient retrieval of information.
- **High-Quality Embeddings**: Powered by Hugging Face Instructor Embeddings for accurate results.

## Technologies Used
- [Streamlit](https://streamlit.io)
- [Langchain](https://github.com/hwchase17/langchain)
- [FAISS](https://github.com/facebookresearch/faiss)
- [Google Makersuite](https://makersuite.google.com)
- [Hugging Face](https://huggingface.co)

## Getting Started
Follow these steps to set up and run the Q&A bot on your local machine.

### Prerequisites
- Python 3.7 or higher
- pip (Python package installer)

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/Online-Learning-QA-Bot.git
   cd Online-Learning-QA-Bot
2. **Install Dependencies:
  Ensure you have all the necessary packages by installing them via requirements.txt.
  ```bash
  pip install -r requirements.txt
  ```
3. ** Set Up API Keys:

- Obtain API keys for Google Makersuite and any other services you plan to use.
- Create a config/ directory and add your API keys in appropriate files (e.g., config/google_api_key.txt).

## Usage

-  Click on "Create Knowledgebase" to initialize the database with your CSV files. This step converts your CSV data into a vector database for efficient querying.

2. Asking Questions:
- Type your question into the provided input box.
- The bot processes the question and provides an answer based on the knowledge base.
